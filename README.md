# Qwen-Image-2.1 на RunPod: пошаговая инструкция

[Qwen-Image-2.1](https://huggingface.co/Qwen/Qwen-Image-2.1) — нейросеть от Alibaba (команда Qwen), которая
**рисует картинки по текстовому описанию** и **редактирует готовые картинки** по текстовой команде. Умеет
писать текст на картинках и делать изображения с прозрачным фоном (PNG).

Этот проект ставит модель на арендованный сервер с видеокартой в [RunPod](https://console.runpod.io/deploy)
и запускает простой сайт-интерфейс: пишете запрос, нажимаете кнопку, получаете картинку.

Нужно сделать 6 шагов. Команды из рамок копируйте целиком, как есть.

---

## Шаг 0. Дайте серверу доступ к этому репозиторию

Репозиторий сейчас **приватный**, и сервер RunPod не сможет его скачать. Выберите один вариант.

**Вариант А (проще): сделать репозиторий публичным.** Секретов в нём нет.
GitHub → этот репозиторий → **Settings** → внизу **Danger Zone** → **Change visibility** → **Make public**.

**Вариант Б: оставить приватным и использовать токен.**
1. Откройте [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new).
2. *Repository access* → **Only select repositories** → выберите `Qwen-Image-2.1`.
3. *Permissions* → **Contents: Read-only**. Нажмите **Generate token** и скопируйте токен (`github_pat_...`).
4. В шаге 4 вместо обычной команды `git clone` используйте:
   ```bash
   git clone -b claude/qwen-image-setup-j83x0r https://ВАШ_ТОКЕН@github.com/shopylepixes-droid/Qwen-Image-2.1.git
   ```

## Шаг 1. Пополните баланс RunPod

[console.runpod.io](https://console.runpod.io) → **Billing** → пополните счёт (хватит $10–25 для начала).
Оплата почасовая: пока сервер включён, деньги списываются, даже если вы ничего не генерируете.

---

## Шаг 2. Создайте сервер (Pod)

Откройте [console.runpod.io/deploy](https://console.runpod.io/deploy).

### 2.1. Выберите видеокарту

Модели нужно около **33 ГБ видеопамяти** (VRAM). Цена за час написана на карточке каждой видеокарты.

| Видеокарта | VRAM | Как работает |
|---|---|---|
| **RTX A6000, A40, L40S, RTX 6000 Ada** | 48 ГБ | ✅ **Рекомендуется.** Работает всё: 1K и 2K, до 10 референсов, прозрачный фон. Текстовая часть модели (16 ГБ) ждёт в оперативной памяти и заходит на видеокарту на пару секунд, чтобы прочитать запрос |
| A100 80GB, H100 | 80 ГБ | ✅ Вся модель на видеокарте. Быстрее всего, особенно в 2K, но дороже |
| RTX 4090, RTX 3090, RTX 5090 | 24–32 ГБ | ⚠️ 1K работает, но медленнее: части модели по очереди подгружаются из оперативной памяти. 2K и много референсов могут не поместиться |
| Карты меньше 24 ГБ | < 24 ГБ | ❌ Не подойдут |

Сколько ждать одну картинку на A40 (40 шагов):

| Что | Время |
|---|---|
| 1K по тексту | ~35 с |
| 1K, 10 референсов | ~1,5 мин |
| 2K по тексту | ~3 мин |
| 2K, 10 референсов | ~5,5 мин |

### 2.2. Выберите шаблон (Template)

Нажмите **Change Template** и выберите официальный шаблон **Runpod Pytorch** — самую новую версию из списка
(нужен PyTorch **2.6 или выше**; в названии шаблона обычно указана версия, например `Runpod Pytorch 2.8.0`).

### 2.3. Настройте диски и порт

Нажмите **Edit Template** (или **Edit**) и поставьте:

| Поле | Значение | Зачем |
|---|---|---|
| **Container Disk** | `30` GB | временные файлы системы |
| **Volume Disk** | `80` GB | сюда сохранятся модель (~33 ГБ), библиотеки и ваши картинки; этот диск **не стирается** при остановке сервера |
| **Expose HTTP Ports** | `8888,7860` | `8888` — Jupyter (терминал), `7860` — наш сайт-интерфейс |

Нажмите **Set Overrides** (или **Save**).

### 2.4. Запустите

- Тип: **On-Demand** (не *Spot*: Spot-сервер могут отключить посреди работы).
- Нажмите **Deploy On-Demand**.

Подождите 1–3 минуты, пока сервер не станет **Running**.

## Шаг 3. Откройте терминал на сервере

**Pods** → ваш сервер → **Connect** → **Jupyter Lab** (порт 8888).
В Jupyter: **File → New → Terminal**. Откроется чёрное окно с командной строкой — это терминал.

*(Если Jupyter не открывается: **Connect → Start Web Terminal → Open Web Terminal**.)*

---

## Шаг 4. Скачайте проект и запустите установку

Скопируйте в терминал и нажмите Enter:

```bash
cd /workspace
git clone -b claude/qwen-image-setup-j83x0r https://github.com/shopylepixes-droid/Qwen-Image-2.1.git
cd Qwen-Image-2.1
bash start.sh
```

Что произойдёт (только в первый раз, **15–30 минут**):
1. Проверка видеокарты, версий и свободного места.
2. Установка библиотек (2–5 минут).
3. Скачивание модели, ~33 ГБ (5–15 минут).
4. Загрузка модели в видеокарту (1–3 минуты).

Установка закончена, когда в терминале появится:

```
Готово! Откройте в RunPod: Connect → HTTP Service [Port 7860]
```

**Не закрывайте терминал**: пока он открыт, сайт работает.

## Шаг 5. Откройте интерфейс и генерируйте

**Pods** → ваш сервер → **Connect** → **HTTP Service [Port 7860]**.
Откроется сайт вида `https://xxxxxxxx-7860.proxy.runpod.net`.

### Вкладка «Создать по тексту»

1. Напишите запрос, например: `A capybara wearing a wizard hat, oil painting`.
2. Выберите **разрешение** и **пропорции**:
   - **1K** — около 1 мегапикселя (1024×1024, 1344×768…), быстро.
   - **2K** — около 4 мегапикселей (2048×2048, 2752×1536…). Это родное разрешение модели, детальнее, но в ~5 раз дольше.
3. Нужен прозрачный фон — поставьте галочку **«Прозрачный фон»**.
4. Нажмите **Создать**.

### Вкладка «Редактировать / по референсам»

1. Загрузите от 1 до **10 картинок**, можно перетащить сразу несколько. Модель читает их в порядке загрузки.
2. Напишите, что сделать. На картинки ссылайтесь по номеру, например:
   - одна картинка: `Move it to a snowy mountain top`;
   - несколько: `Put the person from image 1 into the scene from image 2`
     (или `<image1>`, `<image2>`…).
3. Выберите разрешение (1K / 2K) и пропорции результата: как у первой или последней картинки либо
   одна из стандартных.
4. Нажмите **Создать**.

Чтобы **вырезать объект с фото**, загрузите фото, поставьте галочку «Прозрачный фон» и опишите сам объект:
`The cat from image 1, exactly the same, isolated`.

### Советы

- Пишите запросы **на английском** (или китайском): на них модель обучалась больше всего.
  Можно попросить ChatGPT/Claude перевести ваш запрос.
- Текст, который должен появиться на картинке, берите в кавычки: `a poster with the text "SALE -50%"`.
- **Прозрачный фон** включайте галочкой. Она добавляет к запросу формулировку из инструкции Qwen:
  `This is an RGBA image with transparency. … The image has alpha channel and the background is transparent.`
  Без неё (например, просто `transparent background`) модель рисует обычный непрозрачный фон.
  Картинки сохраняются в PNG с прозрачностью; на сайте прозрачные места могут выглядеть белыми — это нормально.
- Понравилась картинка — запишите её **seed** (показан под результатом). Тот же запрос + тот же seed
  (снимите галочку «Случайный seed») дадут ту же картинку, и можно менять детали запроса.
- Запрос удобно подбирать в 1K, это быстро, а финальную картинку делать в 2K. С тем же seed 2K-версия
  получится другой, но в том же духе.

### Где мои картинки

Все результаты автоматически сохраняются на сервере в папку `/workspace/outputs`.
Скачать: в Jupyter слева откройте папку `outputs`, правый клик по файлу → **Download**.
Или просто кнопка скачивания в углу картинки на сайте.

## Шаг 6. Выключайте сервер, когда не пользуетесь

Иначе деньги продолжат списываться каждый час.

- **Stop** — выключить. Видеокарта больше не оплачивается, диск `/workspace` с моделью сохраняется
  (за его хранение списывается небольшая сумма).
- **Terminate** — удалить сервер **со всеми файлами**. Модель придётся качать заново.

### Как запустить снова после Stop

**Start** → **Connect → Jupyter Lab** → терминал → команда:

```bash
bash /workspace/Qwen-Image-2.1/start.sh
```

Ничего переустанавливать не нужно, через 1–3 минуты сайт снова работает.

> Иногда после Stop видеокарта, на которой был сервер, занята другим клиентом, и сервер не запускается
> или запускается без GPU. Тогда удалите его (**Terminate**) и повторите шаги 2–5 — всё поставится заново.

## Если что-то пошло не так

| Проблема | Решение |
|---|---|
| `git clone` просит логин/пароль | Репозиторий приватный — см. **Шаг 0** |
| `ОШИБКА: Нужен Python 3.10+ и PyTorch 2.6+` | Выбран не тот шаблон. Пересоздайте сервер с шаблоном **Runpod Pytorch** новой версии (шаг 2.2) |
| `ОШИБКА: Мало места` | Увеличьте **Volume Disk** до 80 GB: сервер → **⋮ → Edit Pod** |
| `ОШИБКА: Видеокарта не найдена` | Сервер создан без GPU. Пересоздайте его с видеокартой |
| Сайт показывает ошибку 502 / не открывается | Модель ещё загружается — дождитесь в терминале строки «Готово!». Проверьте, что порт `7860` добавлен в **Expose HTTP Ports** |
| Нет пункта **HTTP Service [Port 7860]** | Порт не открыт. Остановите программу в терминале (`Ctrl+C`) и запустите `bash start.sh --share` — в терминале появится ссылка `https://....gradio.live`, откройте её |
| `Не хватило видеопамяти` / `CUDA out of memory` | Выберите 1K, уберите часть референсов или выключите CFG. Если не помогло, перезапустите с максимальной экономией памяти: `Ctrl+C`, затем `OFFLOAD=on bash start.sh` |
| При скачивании ошибка `401` / `403` / `gated` | Нужен токен HuggingFace: создайте на [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) (тип *Read*), затем `export HF_TOKEN=hf_ваш_токен` и снова `bash start.sh` |
| Закрыл терминал — сайт перестал работать | Запускайте в фоне: `nohup bash /workspace/Qwen-Image-2.1/start.sh > /workspace/app.log 2>&1 &`. Смотреть, что происходит: `tail -f /workspace/app.log` |

## Защита паролем (по желанию)

Ссылка `...proxy.runpod.net` доступна любому, кто её знает. Чтобы закрыть сайт паролем:

```bash
APP_PASSWORD=придумайте_пароль bash /workspace/Qwen-Image-2.1/start.sh
```

Логин при входе — любой, пароль — тот, что указали.

## Для любопытных: что внутри

| Файл | Что делает |
|---|---|
| `setup.sh` | Проверяет сервер, создаёт окружение Python в `/workspace/qwen-venv`, ставит библиотеки, скачивает модель в кэш HuggingFace на диске `/workspace` (в шаблонах RunPod это `/workspace/.cache/huggingface`) |
| `start.sh` | Запускает `setup.sh`, если установки ещё не было, затем интерфейс |
| `app.py` | Сайт-интерфейс (Gradio) и вызов модели через `QwenImage21Pipeline` из библиотеки `diffusers` |
| `requirements.txt` | Список библиотек с зафиксированными версиями |

Настройки через переменные окружения (пишутся перед командой, например `OFFLOAD=on bash start.sh`):

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `OFFLOAD` | `auto` | где держать части модели. `auto` — по объёму видеопамяти: от 70 ГБ `off`, от 40 ГБ `text`, иначе `on`; `off` — всё на видеокарте; `text` — текстовая часть модели в ОЗУ, остальное на видеокарте; `on` — все части по очереди подгружаются из ОЗУ (медленнее всего) |
| `APP_PASSWORD` | — | пароль на сайт |
| `PORT` | `7860` | порт сайта |
| `HF_TOKEN` | — | токен HuggingFace, если понадобится |
| `MODEL_ID` | `Qwen/Qwen-Image-2.1` | какую модель загружать |

Параметры генерации взяты из рекомендаций Qwen: 40 шагов, без CFG (guidance), размеры 2K — из карточки модели.
CFG и негативный промпт можно включить в «Дополнительных настройках», но генерация станет в 2 раза дольше.

Референсы модель читает в разрешении результата. Чтобы 2K с 10 референсами поместился в 48 ГБ, их суммарная
площадь ограничена десятью картинками 1024×1024: один-два референса при 2K идут в полном 2K, больше — уменьшаются.

Отдельные модели для улучшения промптов (`Qwen-Image-2.1-PE-T2I`, `Qwen-Image-2.1-PE-I2I`) не используются.
